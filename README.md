# JANKEN · 極 (GIT-Y3)

提供された建築・素材テクスチャアトラスから自動切り出し＋PBR（法線・粗さマップ）合成した5つの写実的3D舞台で戦う、**非ネオン・高精細3Dじゃんけんゲーム**です。

## 主な搭載技術

- **独自NPCコアエンジン「JNV1.0」** ([詳細設計書](docs/JNV1_ARCHITECTURE.md))
  - 9種の人間行動・心理・時系列予測器（多階マルコフ / 結合状態マルコフ / 循環シフト / Wang-Xu-Zhou心理モデル / 最長一致スナイパー / 連打反動 / 思考テンポ遅延 / 対NPCミラー）＋自己鏡像3種
  - 6階層メタ回転バンク（最大36体の並列専門家）× 非定常 Fixed-Share Hedge 調停 × Page-Hinkley CUSUM 変化点検知 × ナッシュ均衡リスク混合
  - **FIPS 180-4 SHA-256 事前コミット証明**により「後出し不正ゼロ」を毎局リアルタイム検証
- **独自拡張HDRパイプライン「KHDR」**（ON / OFF ＆ リアルタイムA/B分割比較対応）
  - 16-bit HalfFloat レンダーターゲット上の Dual-Scale 対数輝度レティネックス局所適応・色度保存トーンカーブ・表面明瞭度復元・ブルーノイズディザリング
- **独自影エンジン「Shadow Flame 1.0 Flash / 1.0 Pro」**
  - **1.0 Flash**: 軽量1024pxマップ＋IGN回転6タップVogel螺旋PCF＋深度勾配コンタクト硬化＋卓上解析接地AO
  - **1.0 Pro**: 2048px狭視錐台マップ＋10タップPCSSブロッカー探索可変半影＋16タップVogel PCF＋WebGL2深度レイマーチ極微影（SF-SSCS）＋副次リム影
- **高解像度・フレームレート制御**
  - 内部フレームバッファ解像度切替: `HD (1280×720)` / `FHD (1920×1080)` / `1.5K (2240×1260)` / `2K (2560×1440)`
  - フレームレート制御: `60 FPS` / `120 FPS` / `無制限`
- **独自生体関節エンジン「JHand Kinesis 1.0」** ([詳細設計書](docs/JHAND_KINESIS_1_0.md))
  - 27-DOF 解剖学ハンドリグ（前腕回内/回外ツイスト、CMC4/CMC5尺側手掌アーチ、母指カパンジー鞍関節回内、リアルタイム隆起する母指球＆4本の背側伸筋腱コード）
  - 6層生体力学ソルバー：斜支帯靭帯(ORL) DIP–PIP連成(`0.72`) / 4×4腱間結合マトリクス / テノデーシス効果 / 側副靭帯収束＆舟状骨結節ロール / Hill型筋活動遅延＆近位→遠位慣性ウィップ遅延 / カパンジー可動域ソフトストップ＆指間干渉ゼロ保証
- **独自物理モデリング＆3D空間音響エンジン「JSound Engin 1.0」** ([詳細設計書](docs/JSOUND_ENGIN_1_0.md))
  - 外部音声ファイルゼロ・純粋物理DSP合成：ヘルツ接触力学＆最大16次モーダル共鳴（檜象牙・絡繰真鍮銅・京白磁・黒曜金の全素材ペア×5種卓上素材×手種別）＋手打ち仏具おりん球殻共鳴
  - Strouhal渦放出24dB/oct SVF空力風切り音、スティックスリップ鍛造ハサミ剪断、JHand Kinesis 1.0連動マイクロ関節フォーリー＆碁石バウンス物理音
  - 3D鏡像法（24初期反射）＋2帯域Eyringベルベットノイズ畳み込みリバーブ（5建築ステージ別ステレオIR＋デュアルコンボルバA/Bシームレス切替）、3D HRTFバイノーラル定位、舞台環境音、スタジオマスタリング段
- **5つの建築ステージ**
  - 和室・陽だまりの座敷 / 貴賓室・大理石と真鍮の間 / 社殿・苔庭の拝殿 / 湯けむり・石庭の離れ / 工房・赤煉瓦と鉄のアトリエ

## セットアップ & 起動

```bash
npm install
npm run dev
```

```bash
# 全エンジン一括検証（JNV1.0 2,400局 + JHand Kinesis 1.0 10,000ステップ + JSound Engin 1.0 物理DSP/5舞台IR）

```
