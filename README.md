# JANKEN · 極 (GIT-Y3)

提供された建築・素材テクスチャアトラスから自動切り出し＋PBR（法線・粗さマップ）合成した5つの写実的3D舞台で戦う、**非ネオン・高精細3Dじゃんけんゲーム**です。

## 主な搭載技術（v1.2）

- **独自物理モデリング＆3D立体音響エンジン「JSound Engin 1.2」** ([詳細設計書](docs/JSOUND_ENGIN_1_2.md))
  - 外部音声ファイルゼロ・**192kHz 4×オーバーサンプリング（15タップ Kaiser $\beta=6.8$ ハーフバンドカスケード FIR、-65 dB エイリアス抑圧）**＋全**32種**校正済み物理素材
  - **18種の純物理モデリング楽器＆環境アクター**（大太鼓・締太鼓・小鼓・十三絃箏・**津軽三味線・薩摩琵琶・雅楽笙・篠笛・祭摺鉦・楠木魚・玉鋼抜刀・舞扇**・尺八・江戸風鈴・鹿威し・神楽鈴・和紙裂断・梵鐘・おりん）＋左ドロワー内の**15楽器物理試聴デッキ**
  - **4次 128本 3D鏡像法（Image-Source）**＋Woodworth-Schlosberg 球頭 ITD＋垂直耳介高度キュー＋5帯域ベルベットノイズ畳み込みリバーブ、リアルタイム **3D軌道移動パンニング＆物理ドップラーシフト**、ISO 9613-1 距離別空気吸収 LPF、12段スタジオマスタリング（4×OSテープ温感＋真 Mid/Side 空間幅マトリクス、**立体3D / 広域音場 / 集中定位**の3モード切替）
- **独自生体関節エンジン「JHand Kinesis 1.1」× 18種掌形＆9系統バトルモーション** ([詳細設計書](docs/JHAND_KINESIS_1_1.md))
  - **38-DOF 極致解剖学ハンドリグ**＋**18種の解剖学ポーズ**（構え・牽制フリック・手招き・拳鳴らし・手刀エッジ・鶴構え・極一撃クロー・勝利フィンガー・瞑想掌・凱旋拳ほか）
  - 各手3パターンのローテーション必殺演出（全9系統の勝利モーション＋3系統あいこ応酬＋待機パーソナリティ動作＋9チャンネル立体フォーリー送出）
- **Cinema Camera Director 2.0**
  - 5種のカメラワーク（**映画シネマ / 決闘ローアングル / 匠マクロ鑑賞 / 対局俯瞰 / 自由鑑賞**、ショートカット `C`）
  - 14種のシネマムード（肩越し構図・盤面低視点・フェイント覗き込み・気迫チャージ）、極一撃・マッチポイント時の **180°バレットタイム旋回**、Catmull-Rom 3D スプラインクレーン軌道、2本指ピンチズーム＆スマホ縦横自動フレーミング
- **深化されたゲーム性（SHA-256 100%公正事前封印を維持）**
  - **4つの対局モード**：真剣勝負（3先/5先）・**連勝道場**（2連勝ごとに舞台＆人格昇格、最高記録保存）・**刹那3秒**（木魚＆摺鉦カウントダウン）・無制限
  - **気迫ゲージ & 極一撃（Overdrive）**：100%で発動可能、勝利時2点奪取＋玉鋼抜刀×津軽三味線×180°バレットタイム演出
  - **牽制（Feint）**：すでに SHA-256 事前封印済みの JNV1.0 の手を改変せず、相手が出さない1手を読み切る非不正心理戦
- **PVシネマ化＆リアルタイム録画出力（WebM / PNG）**
  - 3種の自動監督トレーラー（**公式PV 26秒 / 激闘リール 16秒 / 工芸＆音響鑑賞 18秒**）を 2.35:1 漆黒レターボックス＋書道タイトルカード＋朱印付きでリアルタイム演出
  - WebGL2 映像＋2.35:1 合成タイトル＋JSound 1.2 マスター3Dステレオ音声を同時収録して **`.webm` 動画としてダウンロード可能**（1クリック 1920×1080 シネマ PNG 静止画保存も対応）
- **スマホ全画面表示＆コンパクト洗練UI**
  - `viewport-fit=cover`・`100dvh`・`manifest.webmanifest`（PWA `display: fullscreen`）・ネイティブ Fullscreen API＋iOS Safari 没入全画面フォールバック搭載
  - 手札カード＆操作アイコンを大幅小型化（デスクトップ `94×76px`・極小 `78×62px`・スマホ縦 `72×58px`・スマホ横 `64×48px`、スマホ上部1行レイアウト）
- **独自NPCコアエンジン「JNV1.0」** ([詳細設計書](docs/JNV1_ARCHITECTURE.md))
  - 9種予測器＋自己鏡像3種・6階層メタバンク（最大36専門家）× Fixed-Share Hedge × CUSUM変化点検知 × ナッシュ均衡リスク混合 × **FIPS 180-4 SHA-256 事前封印証明**
- **独自拡張HDR「KHDR」＆独自影エンジン「Shadow Flame 1.0 Flash / Pro」**
  - 内部解像度切替（`HD` / `FHD` / `1.5K` / `2K`）・FPS制御（`60` / `120` / `無制限`）・KHDR A/B 分割比較・5つの建築ステージ

