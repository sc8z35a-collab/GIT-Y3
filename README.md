# JANKEN · 極 (GIT-Y3)

提供された建築・素材テクスチャアトラスから自動切り出し＋PBR（法線・粗さマップ）合成した5つの写実的3D舞台で戦う、**非ネオン・高精細3Dじゃんけんゲーム**です。

## 主な搭載技術（v1.3 + FINGER S1.0）

- **極写実ハンド造形＆皮膚・関節グラフィックモード「FINGER S1.0」** ([詳細設計書](docs/FINGER_S1_0.md))
  - **非対称 32×24 解剖学的彫刻指節**（平坦背側稜・ふっくらとした指腹パルプ・骨幹くびれ・双顆関節フレア・陥凹爪床・側爪郭・甘皮リム）＋シームレス関節カプセル
  - **3層・動的背側関節皺スタック**（PIP/DIP 伸展で折り畳まれ、屈曲でピンと張るリアルタイム生体変形）＋**二重曲率・爪半月付きネイルプレート**（`IOR 1.53`・クリアコート `0.94`）
  - **手続き型マイクロ解剖 PBR テクスチャ**（渦巻/蹄状指紋、Rete Cutis 毛穴、同心楕円状の関節皺、生命線/知能線/感情線の掌紋、手背静脈弓、爪半月＆縦条紋）
  - **独自 GLSL ヘモグロビン皮下散乱（Wrap-SSS + 逆光透過）＆リアルタイム関節白化（`uS1Effort`）＋産毛グレージング光沢**（Shadow Flame 1.0 / KHDR と 100% 併用可能・非ネオン自然写実）
  - 新規素材プリセット **「極写実肌（`living_skin`）」** を標準搭載し、スタジオドロワーから 0ms で **FINGER S1.0 ON / OFF** 切替可能
- **独自物理モデリング＆3D立体音響エンジン「JSound Engin 1.3」** ([詳細設計書](docs/JSOUND_ENGIN_1_3.md))
  - 外部音声ファイルゼロ・**384kHz 8×オーバーサンプリング（厳密 23タップ Kaiser $\beta=8.2$ ハーフバンドカスケード FIR、-86.5 dB エイリアス抑圧）**＋全**43種**校正済み物理素材（`living_skin` 含む）
  - **大幅な高速化と無劣化化**：Float64 ゼロ三角関数クアドラチャ発振・`-96 dB` 早期終了・Padé `fastTanh`・ゼロアロケーション単一パス 6帯域ベルベットノイズ IR・**マルチバリアント Round-Robin LRU キャッシュ**により低負荷・無スタッタで 384kHz 再生
  - **26種の純物理モデリング楽器＆14種の空間環境音アクター**（新規追加：**龍笛・篳篥・大鼓・鞨鼓・銅鑼・法螺貝・一絃琴・水琴窟**を含む）＋左ドロワー内の **24和楽器 物理試聴デッキ**
  - **5次 230本 3D鏡像法（Image-Source）**＋Woodworth-Schlosberg 球頭 ITD＋3帯域垂直耳介高度キュー＋14段クリスタルクリア・マスタリング（**立体3D / 広域音場 / 集中定位**）
- **独自生体関節エンジン「JHand Kinesis 1.1」× 36掌形＆C²極上ぬるぬる制御** ([詳細設計書](docs/JHAND_KINESIS_1_1.md))
  - **38-DOF 極致解剖学ハンドリグ**＋**36種の解剖学ポーズ**（従来の18種に加え、**蓮華印・剣印（九字）・虎掌打・鳳眼拳・茶筅持ち・舞扇構え・筆執り・箏爪弾き・指パッチン・歌舞伎波動・禅円相**ほか18種を追加）＋スタジオ内の **36掌形モーション試演デッキ**
  - 各手5パターンのローテーション必殺演出（**全15系統の勝利モーション＋5系統あいこ応酬＋10種待機仕草**）
  - **C² ぬるぬるアニメーション基盤**：各指 5次（Quintic）滑らかターゲット補間＋**6×物理サブステップ**、厳密解析解バネ **`AnalyticSpring`**（フレームレート完全不変）、フレームデルタ EMA スパイク平滑化、滑らかな加減速付きシネマヒットストップ
- **Cinema Camera Director 2.1（C² AnalyticSpring ステディカム追従）**
  - 5種のカメラワーク（**映画シネマ / 決闘ローアングル / 匠マクロ鑑賞 / 対局俯瞰 / 自由鑑賞**、ショートカット `C`）＋14種のシネマムード＋極一撃・マッチポイント時の **180°バレットタイム旋回**
- **深化されたゲーム性（SHA-256 100%公正事前封印を維持）**
  - **4つの対局モード**：真剣勝負（3先/5先）・**連勝道場**・**刹那3秒**・無制限、**気迫ゲージ & 極一撃（2点奪取）**、非不正心理戦 **牽制（Feint）**
- **PVシネマ化＆リアルタイム録画出力（WebM / PNG）**
  - 3種の自動監督トレーラー（**公式PV 26秒 / 激闘リール 16秒 / 工芸＆音響鑑賞 18秒**）を 2.35:1 漆黒レターボックス＋書道タイトルカード＋朱印付きでリアルタイム演出、WebM 動画＆1920×1080 PNG 保存対応
- **スマホ全画面表示＆コンパクト洗練UI**
  - `viewport-fit=cover`・`100dvh`・PWA Fullscreen・ネイティブ Fullscreen API＋iOS Safari 没入全画面フォールバック、小型漆塗り手札カード
- **独自NPCコアエンジン「JNV1.0」** ([詳細設計書](docs/JNV1_ARCHITECTURE.md))
  - 9種予測器＋自己鏡像3種・6階層メタバンク（最大36専門家）× Fixed-Share Hedge × CUSUM変化点検知 × ナッシュ均衡リスク混合 × **FIPS 180-4 SHA-256 事前封印証明**
- **独自拡張HDR「KHDR」＆独自影エンジン「Shadow Flame 1.0 Flash / Pro」**
  - 内部解像度切替（`HD` / `FHD` / `1.5K` / `2K`）・FPS制御（`60` / `120` / `無制限`）・KHDR A/B 分割比較・5つの建築ステージ
