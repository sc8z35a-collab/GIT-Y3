# JSound Engin 1.2 — 192kHz 4×OS 立体音響・物理モデリングサウンドエンジン設計書

**JSound Engin 1.2** は、外部音声ファイルを一切使用せず 100% 独自の第一原理物理モデリング DSP によってリアルタイム生成する高解像度・立体音響サウンドエンジンです。

## 1. v1.1 → v1.2 の主要ブレイクスルー

| 領域 | JSound Engin 1.1 | JSound Engin 1.2 |
|---|---|---|
| 内部サンプリングレート | 96 kHz (2×OS, 7-tap FIR) | **192 kHz (4×OS Ultra / 2×OS Pro)** — 15-Tap Kaiser ($\beta=6.8$) Half-Band カスケード FIR（-64 dB 以上エイリアス抑圧） |
| 物理モデリング楽器数 | 10 楽器 | **18 楽器**（津軽三味線・薩摩琵琶・雅楽笙・篠笛・摺鉦・楠木魚・玉鋼抜刀・舞扇を追加） |
| 音響マテリアル定義 | 24 素材 | **32 素材**（サワリ付三味線胴・桑琵琶・竹笙・楠木魚・玉鋼刀身・真鍮鉦・竹和紙扇・御影石燈籠を追加） |
| 空間反射モデル | 3次 62本レイ + 4バンド | **4次 128本 3D Image-Source** + **Woodworth-Schlosberg ITD + 垂直耳介高度キュー** + **5バンド Velvet-Noise** |
| 3D 立体移動 & ドップラー | 静的 HRTF 配置 | **リアルタイム 3D 軌道パンニング + 物理ドップラーシフト + ISO 9613-1 距離別空気吸収 LPF** |
| マスタリング段 | 8段マスタリング | **12段スタジオマスタリング**（4×OS 磁気テープ温感サチュレーション + 真の Mid/Side 空間幅マトリクス + PV録画用 `MediaStreamAudioDestinationNode` 出力） |
| 空間プリセット | 固定 | **立体3D (Binaural) / 広域スタジオ (Studio Wide) / 集中定位 (Focused)** の3モード切替 |
| サウンドカタログ | 28 系統 | **44 系統**（試聴デッキは 15 楽器に拡大） |

## 2. 18 物理モデリング楽器ラインナップ

1. **大太鼓 / 締太鼓 / 心鼓**（非線形ベッセル膜モード + 胴体ヘルムホルツ共鳴）
2. **小鼓**（調べ緒張力によるピッチアップ/ダウン非線形皮膜モデル）
3. **十三絃箏**（Karplus-Strong 物理弦導波路 + 桐共鳴胴）
4. **津軽三味線**（犬皮張膜 + 一の糸「サワリ」非線形バズ + 撥打ち過渡）
5. **薩摩琵琶**（桑胴共鳴 + 柱擦れサワリ + 撥引きピッチベンド）
6. **尺八**（竹管エッジジェット気流 + 3次フォルマント + ビブラート）
7. **篠笛 / 能管**（高次横笛エアジェット・チフ + 艶のあるビブラート）
8. **雅楽・笙**（合竹 6管フリーリード調和クラスター + 息圧スウェル）
9. **仏具おりん**（手打ち真鍮双極子うなりモード）
10. **梵鐘**（大型寺院青銅鐘の低次唸り・長残響）
11. **神楽鈴**（多連真鍮小鈴カスケード）
12. **祭・摺鉦（当り鉦）**（開放鳴り / ミュート打撃の2モード真鍮鉦）
13. **楠・木魚**（空洞スリットドラムのヘルムホルツ木鳴り）
14. **紫檀拍子木**（ステレオ2本紫檀角材の硬質衝撃）
15. **江戸風鈴**（宙吹き薄ガラスの繊細倍音）
16. **鹿威し**（青竹の打撃と御影石反響）
17. **玉鋼・抜刀**（鯉口・鞘擦れ摩擦帯域 + 鍛造鋼の高純度残響）
18. **舞扇（竹骨・和紙）**（鋭い開閉スナップ + 和紙フラッター）

## 3. 検証基準 (`npm run test:jsound`)
- 192 kHz 4×OS 15-Tap Kaiser FIR のパスバンド通過（RMS > 0.68）と 88 kHz エイリアス抑圧（< -55 dB）
- 全 32 音響素材および全 18 物理楽器の有限値・非クリッピング・音色分離保証
- 全 5 建築ステージの 4次 3D Image-Source（100本以上の離散初期反射レイ）＋ 5バンド Velvet-Noise ステレオ相関検査
