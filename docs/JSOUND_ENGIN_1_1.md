# JSound Engin 1.1 — 高解像度 96kHz 2×OS 物理モデリング＆3D空間音響エンジン設計書

`JSound Engin 1.1` は、外部録音ファイル（WAV/MP3）を一切使わず、純粋な音響物理学と高解像度デジタル信号処理（DSP）のみでリアルな音世界を構築する 10 モジュール構成の独自サウンドエンジンです。v1.1 では **内部 2× オーバーサンプリング（96 kHz 相当）高解像度化**、**24種の物理素材＆10種の本格和楽器・環境アクターによる大幅な多種類化**、**3次62光線3D鏡像法＆4帯域ベルベットノイズ残響** を実装しました。

## 1. 高解像度 DSP アーキテクチャ（10モジュール構成）

1. **2× オーバーサンプリング（96 kHz 相当）物理モーダル合成 ([ModalSynthesizer.ts](../src/engine/jsound/ModalSynthesizer.ts))**
   - `1.1 Ultra` モードでは、サブミリ秒のヘルツ接触衝撃と非線形ソフトサチュレーションを内部 2× サンプルレート（48 kHz 出力時 **96 kHz**）で演算。
   - **7タップ線形位相 Kaiser 窓ハーフバンド FIR デシメーションフィルタ** (`decimate2xHalfBand`) により、44 kHz 帯エイリアシング折り返しを **-45.6 dB** 減衰させつつ 0〜20 kHz の倍音透明感を保持。
   - 最大 **24次非調和固有モード**、強打時の非線形テンション・ピッチグライド、奇数/偶数モードの **真ステレオ双極子放射 (Stereo Dipole Mode Radiation)**、手打ち金属・磁器のうなりダブレットを物理合成。
2. **24種の物理校正済みマテリアルスペクトル ([types.ts](../src/engine/jsound/types.ts))**
   - 手の工芸素材 4種（檜象牙・真鍮銅・京白磁・黒曜金）× 舞台卓上素材 5種（欅卓・大理石・朱塗杉・石灰華・煉瓦鉄）＋碁石 2種＋紫檀拍子木＋おりん＋梵鐘＋真鍮脱進機＋鹿威し竹＋江戸風鈴＋神楽鈴＋3種爪クリック＋振子時計＋備長炭＋檜軋み。
3. **10種の純物理モデリング伝統楽器＆環境アクター ([InstrumentSynthesizer.ts](../src/engine/jsound/InstrumentSynthesizer.ts))**
   - **大太鼓 / 締太鼓 / 心鼓**: 円形皮膜の8次ベッセル固有モード ($J_{01}$〜$J_{22}$) ＋強打時の張力ピッチドロップ＋欅胴ヘルムホルツ共鳴
   - **小鼓**: 調べ緒の締め緩めによる音高上昇/下降スイープ（あいこ連打＆互角反発）
   - **十三絃箏**: 分数遅延 Thiran オールパス Karplus-Strong 絹弦ウェーブガイド＋象牙爪アタック＋桐胴3フォルマント共鳴（平調子アルペジオ対応）
   - **尺八**: 歌口ジェットエッジ乱流息音（チフ）＋円筒管倍音＋横隔膜ビブラート
   - **江戸風鈴 / 鹿威し / 神楽鈴 / 和紙裂断（チョキ勝利） / 梵鐘（決着鐘） / Minnaert 気泡水滴**
4. **3×3 じゃんけん相性別デュアルマテリアル衝突音響**
   - プレイヤー手素材 × NPC手素材 × 舞台卓上素材に加え、**グー粉砕（大太鼓連動）／チョキ一閃（和紙裂断＋スティックスリップ剪断）／パー包摂（小鼓＋おりん）／あいこ反発（小鼓上昇）** を毎局物理合成。
5. **4種袖布 Strouhal 空力風切り音 & 9チャンネル JHand 1.1 マイクロフォーリー ([AeroAndFrictionSynth.ts](../src/engine/jsound/AeroAndFrictionSynth.ts))**
   - 手の工芸素材に連動する4種の袖布プロファイル（正絹着物・天鵞絨袖・金襴緞子・漆塗袖）で Strouhal 渦放出則 ($f_s = St \cdot v / D$) を駆動。
   - `JHand Kinesis 1.1` の 3D ランドマーク座標へ全9種の関節・爪・腱・袖フォーリーを HRTF 空間配置。
6. **3次 3D鏡像法（最大62光線）＋ISO 9613-1 空気吸収＋4帯域ベルベットノイズ IR ([StageAcoustics.ts](../src/engine/jsound/StageAcoustics.ts))**
   - 5つの建築ステージそれぞれの実寸・壁/天井/床の Sabine 吸音率から **62本の離散初期反射光線**（ITD/ILD・距離空気減衰込み）と **4帯域（<260Hz / 260-1200Hz / 1.2-4.2kHz / >4.2kHz）拡散残響テイル** を生成。デュアルコンボルバ A/B でシームレス切替。
7. **生きた 3D 空間サウンドスケープ ([StageAmbience.ts](../src/engine/jsound/StageAmbience.ts))**
   - 5.6秒シームレスステレオ環境床に加え、各舞台固有の3D空間アクター（座敷の鹿威し＆江戸風鈴、貴賓室の振子時計、社殿の神楽鈴＆檜軋み、湯殿の洞窟水滴、工房の備長炭＆脱進機）が非反復で空間発音。
8. **3段階品質モード & 物理楽器試聴デッキ ([JSoundEngine.ts](../src/engine/jsound/JSoundEngine.ts))**
   - `1.1 Ultra`（96kHz 2×OS・24モード・62光線・HRTF）／`1.1 Pro`（48kHz・12モード・24光線・HRTF）／`1.1 Lite`（軽量合成）を即時切替可能。
   - 左スタジオドロワー内の **物理楽器試聴デッキ（8楽器）** から、現在選択中ステージの建築残響そのままに各楽器を単体試聴可能。

- 全5舞台 IR：**62本の3次初期反射光線**、L/R相関係数 `0.00〜0.02`（完全広帯域ステレオ分離）
- **12/12 項目すべて PASS**
