# JNV1.0 / KHDR / Shadow Flame 1.0 技術設計仕様書

## 1. 独自NPCコアエンジン「JNV1.0」設計仕様

**JNV1.0 (Janken Non-stationary Inference & Volatility Core v1.0)** は、人間の非定常な行動変化・心理バイアス・再帰的裏読み（メタ読み）へ実時間適応しながら、理論的な被搾取耐性（ナッシュ均衡防御）と **SHA-256事前コミットによる完全な不正ゼロ証明** を両立する7層構造のじゃんけん推論エンジンです。

### 1.1 完全不正ゼロ証明プロトコル（Pre-Commit Seal）
従来のじゃんけんNPCに見られがちな「入力後読み（後出し）」を構造上不可能にするため、JNV1.0は以下の2段階プロトコルで動作します。
1. **事前封印 (`commitNextMove`)**: プレイヤーが手を入力する**前**に、過去履歴 $H_{1..t-1}$ のみから次局の手 $N_t$ をサンプリングし、乱数ソルト $s_t$ と結合した文字列 `JNV1.0|R{t}|{MOVE}|{salt}` の **FIPS 180-4 SHA-256 ダイジェスト**を画面へ即時公開します。
2. **開示・検証 (`revealAndObserve`)**: プレイヤーの手 $P_t$ が確定した瞬間、封印済みの $(N_t, s_t)$ を開示してダイジェスト一致を自動検証し、その後に全予測器と専門家重みをオンライン更新します。

### 1.2 7層推論アーキテクチャ
1. **状態代数層 (`types.ts`)**: 手を巡回群 $\mathbb{Z}_3 = \{0:\text{Rock}, 1:\text{Scissors}, 2:\text{Paper}\}$ として表現。相性関係 $\text{counter}(m) = (m+2)\bmod 3$、相対シフト $\Delta_t = (P_t - P_{t-1})\bmod 3$、結合状態 $J_t = 3P_t + N_t \in \{0..8\}$ を統一演算。
2. **多地平線・行動予測層 (`predictors.ts`) — 9種＋自己鏡像3種**:
   - **P1 指数減衰・頻度分布**: Dirichlet-Multinomial オンライン推定（忘却率 $\gamma=0.94$）。
   - **P2 多階マルコフ連鎖 (`Order 1..4`)**: プレイヤー手列の可変次数サフィックス木＋指数減衰平滑化。
   - **P3 結合状態マルコフ (`Order 1..3`)**: 相互の手ペア $(P, N)$ 履歴からの条件付き遷移推定。
   - **P4 循環シフト予測 (`Order 1..3`)**: 絶対手ではなく回転不変な相対シフト $\Delta_t$（継続 / 順送り / 逆送り）を追跡。
   - **P5 心理条件応答モデル (Wang-Xu-Zhou 2014)**: 直前勝敗（勝後継続・敗後転換）および「あいこ連続回数（Aiko Chain）」に応じた行動心理学的事前分布＋ベイズ逐次更新。
   - **P6 履歴最長一致スナイパー**: 結合履歴・プレイヤー履歴を遡及走査し、最長かつ直近の一致パターンの次手を捕捉。
   - **P7 連打反動・ギャンブラー錯誤検知**: 同手2連打以上の後に人間が無意識に回避する反動傾向を捕捉。
   - **P8 思考テンポ・遅延プロファイル**: 反応時間（ms）を移動平均・移動分散でZスコア化し、即断時と熟考時の手傾向差をオンライン分離。
   - **P9 対NPCミラー・後追い検知**: プレイヤーが直前のJNV手をコピーまたは後追い対抗する反射を捕捉。
   - **S1〜S3 自己鏡像予測器**: JNV1.0自身の過去手列を分析し「人間がJNVの癖を読んで裏をかく手」を逆予測。
3. **6階層メタ回転バンク (`metaBank.ts`)**: 各予測器に直読 `M0` / 2次裏読み `M1` / 3次深読み `M2`（自己鏡像と合わせ実質6階層）を展開し、最大 **36体の専門家** を毎局並列評価。
4. **非定常割引ヘッジ調停器 (`arbiter.ts`)**: Herbster-Warmuth Fixed-Share 混合付き指数割引乗法重み更新（Discounted Hedge / EXP3-MWU）。プレイヤーが途中で戦術を切り替えても休眠専門家が2〜3局で即座に覚醒。
5. **変化点検知・自己被搾取ガード (`volatility.ts`)**: Page-Hinkley CUSUM による非定常レジーム変化検知と、JNV自身の低エントロピー・連敗圧を監視する被搾取リスク指標を算出。
6. **ナッシュ均衡リスク制御選択器 (`JNVCore.ts`)**:
   $$\pi_{\text{final}}(a) = (1 - \beta_t)\,\text{Softmax}\!\left(\frac{Q(a)}{\tau_t}\right) + \beta_t \cdot \frac{1}{3}$$
   優位性が薄い序盤や完全ランダム相手には $\beta_t$ を自動で引き上げ、理論下限（勝率50%）を割り込まない安全性を保証。
7. **説明可能テレメトリ＆ベンチマーク (`benchmark.ts`)**: 毎局の主導専門家・予測確率・CUSUM信号・行動プロファイルを日本語で可視化。8種の合成ボット×各300局（計2,400局）のCLI検証で全 exploitable ボットに対し **68.9%〜98.3%** の決定勝率、完全ランダムに対し **~50%** の無搾取均衡、および **100% SHA-256 検証一致** を実証済み。

## 2. 独自拡張HDRパイプライン「KHDR」技術仕様

**KHDR (Kinetic Dual-Lobe Spectral HDR)** (`src/graphics/KHDRPipeline.ts`) は、WebGL2 の16bit浮動小数点レンダーターゲット (`HalfFloatType`) 上で動作する非ネオン・写実写真志向のマルチパスHDRエンジンです。

1. **Dual-Scale 対数輝度レティネックス局所適応**: Karis重み付きダウンサンプル＋分離型9タップガウシアンで広域照明場 (`localLogLum`) と高周波素材ディテール (`detailLog`) を分離。暗部の木目・石目・畳の編み目と、直射日光下の障子・白磁ハイライトを潰さず両立。
2. **Spectral 知覚ハイライト・ロールオフ**: 輝度と色相比を保つ独自トーンカーブにより、高輝度反射（真鍮・漆・水面）が白飛びや不自然な色転びを起こさず暖かな光沢を維持。
3. **Micro-Specular 表面明瞭度補正**: クランプ付き高周波ディテール復元でリング偽輪郭を出さずに立体感を強化。
4. **物理レンズ光学ベール（非ネオン）**: 極端な太陽光輝度（$L > 1.75$）のみにごく微細な写真レンズ散乱を付加。
5. **Interleaved Gradient Blue-Noise ディザリング**: 漆喰壁や青空グラデーションの8bitバンディングを完全除去。

## 3. 独自影エンジン「Shadow Flame 1.0 Flash / Pro」技術仕様

**Shadow Flame 1.0** (`src/graphics/ShadowFlame.ts` + `KHDRPipeline.ts` + `StageBuilder.ts`) は、Three.js のグローバル影シェーダーチャンクへ直接統合された独自リアルタイム影システムです。

### Shadow Flame 1.0 Flash（超軽量・高写実）
- **軽量 `1024×1024` 影マップ** でありながら、ピクセル単位の **Interleaved Gradient Noise (IGN)** 回転を掛けた **6タップ黄金角 Vogel 螺旋 PCF** により階段状ジャギーを解消。
- 中心深度差 `zReceiver - zCenter` による **1ステップ深度勾配コンタクト硬化** で、卓上付近の影は引き締め、持ち上げた手の影は柔らかく拡散。
- 卓上解析コンタクトAOシェーダー（両手の3D掌中心高さに連動）を併用し、超軽量負荷のまま極上の接地感を実現。

### Shadow Flame 1.0 Pro（最上位物理影）
- **`2048×2048` 狭視錐台影マップ + 副次リム影マップ (`1024×1024`)** の二灯シャドウ構成。
- **10タップ IGN-Vogel PCSS ブロッカー探索**: 遮蔽物と受影面の物理距離を実測し、光学的に正確な可変半影幅（Contact-Hardening Penumbra）を計算（完全日向領域はアーリーアウト最適化）。
- **16タップ余弦重要度重み付き Vogel 螺旋 PCF**: 滑らかかつ引き締まった物理半影を描画。
- **Screen-Space Contact Shadow Ray-March (`SF-SSCS`)**: WebGL2 ハードウェア `DepthTexture` を用い、太陽ベクトル方向へ10ステップのスクリーンスペース深度レイマーチを実行。影マップ解像度では捉えきれない指同士の隙間・真鍮関節ピン・座布団の皺・卓上碁石の極微細接地影を彫り出します。
