# JHand Kinesis 1.0 — 27-DOF Biomechanical Hand Articulation Engine

**JHand Kinesis 1.0** (`src/engine/jhand/`) は、「JANKEN · 極」のためにゼロから設計・実装した**27自由度（27-DOF）生体力学ハンド関節エンジン**です。単純なオイラー角補間や独立バネではなく、Kapandji関節生理学に基づく**6層バイオフィジクス・パイプライン**により、指のしなり・腱の張り・手掌アーチの丸み・衝突回避までを実時間で解き明かします。

## 6層アーキテクチャ

| 層 | 名称 | 実装技術と生体再現効果 |
|---|---|---|
| **Layer 1** | **27-DOF 骨格・対立姿勢生成器** | 前腕回内/回外（`forearmPronation`）＋手関節3軸＋**第4・第5手根中手関節（CMC4/CMC5）**＋母指鞍関節（Kapandji対立回内）＋4指16軸。 |
| **Layer 2** | **腱連動マトリクス** | ① **斜支帯靭帯（ORL）DIP–PIP 連成**（$\theta_{\text{DIP}} \approx 0.67\,\theta_{\text{PIP}} + 0.33\,\theta_{\text{cmd}}$）<br>② **指伸筋間連結腱（Juncturae Tendinum）** 4×4行列（薬指↔中指・小指の共鳴引き込み）<br>③ **腱固定効果（Tenodesis Effect）**（手首背屈で指が自然に軽く丸まる）<br>④ **手掌横アーチ（CMC4/CMC5）カップ変形**＆母指球膨隆（`thenarBulge`）。 |
| **Layer 3** | **側副靭帯・収束軸ソルバ** | MCP屈曲に比例して側副靭帯が外転可動域を狭め、同時に各指を舟状骨結節方向へ微細傾斜（`CONVERGENCE_FACTORS`）させ、握り拳を自然に中央へ収束。 |
| **Layer 4** | **Hill型筋活性化＋近位→遠位慣性鞭伝播** | 各指節に解剖学的慣性モーメント（$I_{\text{MCP}} > I_{\text{PIP}} > I_{\text{DIP}}$）と筋活性化ラグを割り当て、手首加速度から逆慣性トルクを遠位指先へ伝播（振り上げ時のしなり・急停止時の鞭スナップ）。 |
| **Layer 5** | **非線形靭帯ソフトストップ＆自己衝突ソルバ** | 関節可動域（`ANATOMICAL_ROM`）端の2次復元トルク、隣指カプセル間隔保持、**母指クリアランス回避**（握り込み時に人差指と干渉せず外側を回ってロック）、掌接触クッション。 |
| **Layer 6** | **生理学的微細振戦＆音響フォーリー連携** | 筋緊張度に応じた 8–12 Hz 生理学的微細振戦、待機時の自然な呼吸・指波、および **JSound Engin 1.0** へ直結する関節マイクロイベント（`palm_clench` / `knuckle_snap` / `finger_whip` / `scissors_shear`）出力。 |

## 3D造形メッシュ統合（`src/scene/HandRig.ts`）
- **独立前腕回内ピボット（`forearmPivot`）**: 手首だけでなく袖口・手首骨格ごと自然に回内／回外捻りを表現。
- **可動尺側手掌セグメント（`cmc4Pivot` / `cmc5Pivot`）**: グー・チョキ時に薬指・小指側の中手骨と小指球が実際に内側へ折り畳まれる。
- **4本の手背伸筋腱コード（`dorsalTendonMeshes`）**: 指の伸展・握り込み張力に連動して、手の甲の4本の腱が物理的に浮き上がり・緊張する。
- **動的母指球メッシュ（`thenarMesh`）**: 親指の対立運動に合わせて母指球が膨隆・回旋。
