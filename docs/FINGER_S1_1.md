# FINGER S1.1 — ズーム倍率で細かさが変わる 2× HD ハンドディテール

FINGER S1.0 の写実的な肌を、**ズーム倍率に合わせて細かさが上がる**ように作り直しました。テクスチャもメッシュも 2倍の精細さです。検証は `npm run test:fingers11`（11項目すべて合格）です。

## 1. ズーム倍率で切り替わる4段階 (`FingerS11DetailGovernor`)

| 段階 | 切り替わる倍率 | 内容 |
|---|---|---|
| 0 標準 | 2.5× 未満 | S1.0 のテクスチャとメッシュ、肌の凹凸4段 |
| 1 HD 2× | 2.5× 以上 | 2048² 指・手のひら、1024² 細部・爪テクスチャ、2倍細かいメッシュ、凹凸6段 |
| 2 超精細 | 12× 以上 | ＋ 角質細胞（36µm） |
| 3 顕微 | 90× 以上 | ＋ 角質細胞のふち（17µm）、凹凸8段すべて |

段階を下げるのは、倍率が「切り替え倍率 ÷ 1.35」を下回ったときだけです（ヒステリシス）。そのため、切り替え倍率の近くでズームしても表示がチラつきません。現在の段階は、画面右の拡大鏡に「標準 / HD 2× / 超精細 / 顕微」と表示されます。

## 2. 2倍細かいメッシュ（ポップしない切り替え）

- 手のすべての部位で、縦横それぞれ2倍に分割します。三角形は 3.85倍以上になります（手のひらは 4,056 → 16,432）。
- HD メッシュは S1.0 と**まったく同じ数式の曲面**の上に頂点を置いています（共通する点のずれ 0m）。切り替えた瞬間に形が飛びません。
- メッシュは 3ms ずつ分けて作り、全部そろってから一度に差し替えるので、ズーム中にカクつきません。

## 3. 2倍解像度のHDテクスチャ (`FingerS11TextureSynth.ts` / `FingerS11Texture.worker.ts`)

- 指・手のひらは 1024² → **2048²**、細部の肌・爪は 512² → **1024²** です（画素数4倍）。
- 2本の Web Worker で合成するので、メイン画面は止まりません（合計約5.2秒）。指から先に届けて、一番よく見る部分から細かくなります。
- 単に S1.0 を2倍に拡大したものではありません。S1.0 の解像度では表せない細かさの凹凸が **4.6倍**含まれています。
- 指紋の隆線は本物と同じ約0.45mm 間隔です。指先の腹を横切る隆線の数は 14本 → **38本**になりました。分岐や汗孔もあります。
- 粗さ（ラフネス）を色テクスチャのアルファに入れたので、1部位あたり3枚だったテクスチャが2枚で済みます。HD 一式は、ミップマップ込みで約106MB です。
- POCO F7 級（12GB）の端末では、**待機中に先に合成しておく**ので、最初のズームから HD になります。それ以外の端末でも、1.6× まで拡大した時点で合成を始め、2.5× に達する頃には間に合うようにしています。

## 4. MICRO-DERMA FRACTAL 2.0（シェーダー）

肌の凹凸を8段で解析的に計算します：皮膚のしわ（ランゲル線）→ 皮丘 → 皮溝と毛穴 → 指紋の隆線と汗孔 → 細かいしわ → 角質のはがれ → 角質細胞（36µm）→ そのふち（17µm）。周期でいうと 3.8mm から 17µm までです。

- 各段は、高さと一緒に**正確な傾き（勾配）**を返します。差分で求めた値と 1×〜5000× のすべてで一致しています（誤差0.1%未満）。
- 傾きは Mikkelsen のサーフェス・グラディエント法で合成し、three.js の**メインの PBR 法線**に入れています。太陽光、環境の映り込み、クリアコートのすべてが細かい凹凸に反応します。（S1.0 では、追加の光の項にしか効いていませんでした。）
- 1画素あたりの大きさに合わせて各段をフェードイン（1周期 2.5〜6画素）するのでチラつきません。画面より大きすぎる段は消すので、どの倍率でも1画素あたり約4段しか計算しません。
- 凹凸の傾きは、平均 0.083、最大 0.75 と人の肌として自然な範囲です。

## 5. GPU 負荷ガバナー

フレームが遅いとき（34ms）は、一番細かい段から計算を止めます（8段 → 5段）。速くなれば（9ms）元に戻します。KIWAMI MOBILE CORE の動的解像度と組み合わせて、ズーム中も滑らかさを保ちます。
