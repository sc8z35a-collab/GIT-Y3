# JSound Engin 1.3 — 384kHz 8×OS 超クリア・ゼロジッター立体音響＆物理モデリング設計書

**JSound Engin 1.3** は、外部音声ファイルゼロの第一原理物理モデリング DSP において「超高解像度＆圧倒的クリアさ」「サブミリ秒級パフォーマンス」「26和楽器×43素材の極限バリエーション」を同時に達成するために新規設計されたサウンドエンジンです。

## 1. v1.2 → v1.3 の主要ブレイクスルー

| 領域 | JSound Engin 1.2 | JSound Engin 1.3 |
|---|---|---|
| 内部サンプリングレート | 192 kHz (4×OS, 15-tap FIR) | **384 kHz (8×OS Ultra / 4×OS Pro / 2×OS Lite)** — **23-Tap Kaiser ($\beta=8.2$) Half-Band カスケード FIR（実測 `-86.5 dB` エイリアス抑圧・パスバンド平坦度 `<0.002 dB`）** |
| 演算性能・ゼロジッター | 毎回新規合成 + `Math.tanh` | **IEEE-754 Float64 複素回転子 + `-96 dB` 適応早期終了 + Padé 有理サチュレータ + マルチバリアント・ラウンドロビン LRU バッファキャッシュ（再発音 `<0.02 ms`）** |
| 物理モデリング楽器数 | 18 楽器 | **26 楽器**（**龍笛・篳篥・大鼓・鍛造青銅銅鑼・法螺貝・一絃琴（4点Cubic Hermite補間）・鞨鼓高速ロール・京都水琴窟**の8大楽器を新規開発） |
| 音響マテリアル定義 | 32 素材 | **43 素材**（FINGER S1.0 `living_skin` 生体掌肌＋雅楽・能楽・茶庭素材10種を追加） |
| 空間反射・残響 | 4次 128本レイ + 5バンド | **5次 230本 3D Image-Source** + **3帯域耳介高度カーネル** + **ゼロアロケーション単一パス 6バンド Velvet-Noise（5,200 pulses/sec、RAM 1/10・生成 3× 高速化）** |
| マスタリング段 | 12段 | **14段 Crystal Clarity マスタリング**（24Hz HPF → 290Hz 濁り整理ノッチ `-1.2 dB` → 3.1kHz 輪郭 → 11.2kHz クリスタルエアー → 4×OS テープ艶 → 真 M/S 空間幅 → `-0.5 dBFS` True-Peak リミッター） |
| カタログ / 試聴デッキ | 44 系統 / 15 楽器 | **64 系統 / 24 楽器（4×6 物理試聴デッキ）** |

## 2. 検証基準 (`npm run test:jsound`)
- 23-Tap Kaiser ($\beta=8.2$) Half-Band FIR の 2×/4×/8×（384kHz）デシメーション検証（ストップバンド抑圧 `<-80 dB`）
- 全 43 物理素材 & 全 26 物理楽器（32 奏法バリアント）の有限値・非クリッピング・スペクトル分離保証
- 全 5 建築ステージの 5次 230本 3D 鏡像反射＋6帯域ゼロアロケーション Velvet-Noise IR 検証 & 生成速度ベンチマーク
