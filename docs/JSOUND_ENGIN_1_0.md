# JSound Engin 1.0 — Physical-Modeling & 3D Spatial Acoustic Engine

**JSound Engin 1.0** (`src/engine/jsound/`) は、外部録音ファイルに一切依存せず、純粋な音響物理学とリアルタイムDSPだけで「工芸素材の質感」「3D空間の空気感」「建築ごとの反響」まで再現するために一から自作した独自サウンドエンジンです。

## 8モジュール・パイプライン設計

1. **物理モーダル共振＆ヘルツ接触合成 (`ModalSynthesizer.ts`)**
   - 衝突速度 $v$ に応じて接触パルス幅が非線形に短縮される**ヘルツ接触力学**（$\tau_c \propto v^{-0.22}$）＋微細表面粗さ（micro-asperity grain）で励振。
   - 檜象牙・真鍮銅・京白磁・黒曜金・欅卓・大理石・紫檀拍子木・仏具おりん・真鍮脱進機の**最大16次非調和固有振動モード**を再帰直交発振器で高速合成。
   - 手打ち青銅や仏具おりん特有の**モード分裂うなり（Beating Doublets: $\Delta f = 1.7\text{–}3.4\text{ Hz}$）**を再現。
   - 強打するほど高次倍音が強調される物理的スペクトル輝度変化と、1打ごとの微小デチューンで機械的反復感を排除。

2. **異素材カップリング衝突合成 (`synthesizeDualMaterialClash`)**
   - 「プレイヤーの手の素材 × JNV1.0の手の素材 × ステージ卓上素材 × 勝ち手（グー低域圧縮／チョキ鍛造刃高次倍音／パー和紙風裂）」の4要素を同時結合。設定で手の素材や舞台を変えるだけで、衝突音が物理的に変化します。

3. **ストローハル流体風切り＆スティック・スリップ摩擦 (`AeroAndFrictionSynth.ts`)**
   - 腕・袖の振りを流体力学の**ストローハル渦放出則**（$f_s(t) = \mathrm{St}\cdot v(t)/D$）に基づく可変SVFバンドパス＋絹布乱流シマーで合成。
   - チョキ二連斬りでは**スティック・スリップ摩擦**と高次刃先モードを結合。

4. **JHand Kinesis 1.0 リアルタイム関節フォーリー連動 (`playHandFoley`)**
   - 27-DOF生体ハンドエンジンが発火する指節スナップ（`knuckle_snap`）、拳握り込み（`palm_clench`）、指弾き（`finger_whip`）、二連刃剪断（`scissors_shear`）を、現在の手の工芸素材と3Dワールド座標へリアルタイム同期。

5. **3D虚像法（Image-Source Method）レイトレース初期反射＋Velvet-Noise残響IR (`StageAcoustics.ts`)**
   - 全5建築ステージの物理寸法 $(L_x, L_y, L_z)$ と壁・天井・床のSabine吸音率から、最大24本の3D鏡像反射音（正確な到達遅延＋方位角ITD/ILD）と、2帯域Eyring減衰を持つ非相関Velvet-Noise後期残響IRを自動生成。
   - **デュアルConvolver A/Bクロスフェード**により、ステージ切替時もクリック音ゼロで空間響きがシームレスに移行。

6. **生きた建築ステージ環境音 (`StageAmbience.ts`)**
   - 等電力循環クロスフェードによるシームレス・ステレオ環境音（特に「湯けむり・離れ」では多層石灰華の滝＋Minnaert気泡チャープ水滴音を物理合成）。

7. **3D HRTF バイノーラル空間パンニング (`JSoundEngine.ts`)**
   - ProモードではWeb Audio `PannerNode(HRTF)` を用い、Three.jsカメラ視点と両手・脱進機・碁石皿の3D実座標を一致させて立体定位。

8. **スタジオ・マスタリングチェーン＆リアルタイム計測**
   - アナログ風チルトEQ（低域の木の温もり＋高域の絹シマー）→ ソフトニー・バスコンプレッサー → `-1.5 dBFS` トゥルーピーク保護リミッター → `AnalyserNode` 実時間RMS/Peak dBFS計測。

## 自動DSP監査
`npm run test:jsound` により、全4工芸素材の物理輝度順・ヘルツ速度スペクトル応答・ストローハル風切り法則・全5ステージIRのステレオ非相関性と数値健全性をオフラインで自動検証します。
